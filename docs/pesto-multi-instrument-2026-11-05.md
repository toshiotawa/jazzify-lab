# PESTO 複数楽器・生音程出力の初期評価（2026-11-05）

現行stg `ca0a5db310f5677aa47b25a46b9ac92ca2177179` を基準に、実配信compact-v2の生prediction/confidenceを比較した。ゲームの発音判定、期待音補助、低音シフトを通さない。学習済み重みの変更・追加学習は行っていない。

70サンプル、12音源ID、7分類（ピアノ/鍵盤系/ギター/ベース/フルート/金管系/歌声サンプル）、各6条件、計420試行・54,600回の実WASM推論。参照は名目MIDI音番号。以下の値は「名目音番号から50cent以内のフレーム割合」であり、フレーム別実測F0に対する正式なRPAや、ゲームの打鍵正答率ではない。

録音サンプルを使うが、マイク実機、連続歌唱、レガート、同音連打、伴奏混入は測っていない。鍵盤の分類名だけでピアノ機種を特定せず、具体的なピアノとして既存Felt Pianoの元録音7音も別分類で評価した。短音は録音の先頭を人工切断した条件で、実奏の短音とは区別する。

## 観測から分かった優先課題

- フルートのclean sustainは名目音高一致98.1%に対しconfidence付きrecall66.2%。「音程はほぼ合うが確信度で落ちる」種類の弱点がある。アプリの閾値を下げれば全楽器で改善するという根拠にはしない。
- 一部の鍵盤・ギターには、confidenceが1.0でも名目音番号と不一致になる例がある。`guitar_acoustic_001-048-100`は100〜600msの代表点でpredictionが約48.6667。名目48から約66.7centずれ、オクターブ不一致とは別の問題である。
- `keyboard_acoustic_000-036-100`とFelt Piano `f36L`の代表点もprediction約48.6667、confidence1.0だった。低音側で同じ値へ寄る例があり、confidenceを下げるだけでは直らない。
- 上記3音源にFelt `f60L`とフルート`072-100`を加え、元の17MB refill ONNXでも同じPCMを5msずつ逐次再生した。100/200/300/400/500ms付近の出力傾向はcompact-v2と同じだった。少なくとも代表例はcompact軽量化によって新しく発生したものではない。これは元のPyTorch版との一致確認ではない。
- 独立したFFTの補助確認では、ギター48の130Hz近傍や低音鍵盤36の約65Hz間隔の倍音が存在する。Felt60の強いピークは約264/528Hz。この確認だけで全フレームの真のF0を確定しないが、波形を異なるサンプルレートで読んだだけという説明は支持しない。
- −24dBで持続部の生音程一致率はほぼ変わらなかった。この音源subsetでは入力振幅だけの低下に対してモデルは比較的安定していた。ただし音声処理による演奏成分の抑制・欠落、マイクのノイズ増加を再現した試験ではない。

このため、**追加学習の前に、代表的な不一致音を元PyTorchチェックポイント・書き出し時の前処理/デコードと照合する**のを優先する。今回測定したのは現在の配信ONNXの弱点であり、PESTO手法そのものや学習済み重みだけの限界と断定しない。分布外の楽器の問題と、書き出し/音程較正の問題を分けたうえで再学習を判断する。

## 追加学習の判断

この測定は弱点探索と今後の比較の基準であり、追加学習による改善を測定したものではない。候補モデルは未作成なので、他楽器での改善・非悪化はまだ主張しない。

再学習へ進む前に、低一致率の音源をフレーム別F0ラベルや独立した音響解析で点検し、「名目MIDIとの不一致」「本当のF0誤り」「確信度不足」「初期履歴の不足」を切り分ける。短音の先頭と持続部の差は、学習で改善できる部分と、音程判断に必要な観測長・前処理の影響が混在する。

学習を試す場合は複数楽器を混ぜ、楽器個体/サンプル音源ID/歌い手を単位にtrain・調整用validation・最終testを分離する。今回の結果を見て選んだ手法は、このsubsetに適応した可能性があるため、別の未使用録音で最終評価する。特にベースとFelt Pianoは各1音源IDしかなく、この素材内だけではそれらの個体間汎化を検証できない。実マイク、別音源個体、実際の歌唱フレーズ、レガート・連打・伴奏条件を追加してから効果を判断する。

比較コマンドにはcandidate.onnxと学習instrument/speakerグループ一覧を渡す。同じPCM・評価条件を要求し、学習グループが今回の評価音源に含まれる候補は拒否する。全体平均だけでなく各楽器・音源・音域・条件・velocity・phaseと各音源×条件×phaseを照合し、1 percentage point超の悪化は非ゼロ終了。参照カバレッジがない楽器は判定不能にする。申告された学習グループの完全性や、元PESTOの学習素材との完全な非重複を証明するものではない。
